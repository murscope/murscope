# Brand

## The code is yours

This project is MIT licensed. Copy it, fork it, sell it, embed it in
something else, strip out the parts you dislike. You owe nobody a
notification and nobody an explanation. That is the whole point of the
license and there is no asterisk on it.

## The name is a request, not a restriction

The name `murscope`, the wordmark and the default palette are not
protected by the MIT license, and this file does not try to protect them.
It asks.

If you fork this and ship it to other people, please change the name and
change the palette. Not because you have to - because a user who
downloads something called `murscope` should get the thing this
repository builds. If two different tools answer to the same name, the
promises on the front page stop meaning anything, and the promises are
most of what this project is.

Concretely, a fork that ships to users:

- picks its own name, not `murscope` and not a near-miss of it;
- picks its own accent colour and its own dashboard header;
- does not present itself as this project, an official build of it, or
  an endorsed version of it;
- may of course say, plainly and accurately, that it is a fork of
  murscope. That is welcome, and a link back is appreciated.

A private fork you never distribute can do whatever it likes. Nobody is
confused by a tool with one user.
